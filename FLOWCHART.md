## Data Flow Summary

```
1. USER INPUT (Target + Optional Previous Report)
        │
        ▼
2. CORE ENGINE (Load Plugins → Parallel Execution → Collect Results)
        │
        ▼
3. INTELLIGENCE LAYER (Correlate → Enrich → Map Compliance → Delta)
        │
        ▼
4. REPORT GENERATION (JSON + HTML Dashboard)
```

## Plugin Interface

```
┌─────────────────────────────────────────┐
│         BaseScanner (Abstract)          │

│ + parse_output() → Dict                │
│ + get_standardized_output() → Dict      │

│         ↑                               │

│  │NmapPlugin   │  │NiktoPlugin  │      │

│  │+ run()      │  │+ run()      │      │

```
