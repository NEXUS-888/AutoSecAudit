## Notes
- I couldn't run Python this round because Bash and PowerShell were denied. The collisions above come from reading the code: in each case the fingerprint inputs are literally identical in the dicts shown.
- After this change, previous reports saved without structured fields fall back to `tool|title`, while new findings use the structured fingerprint. The first delta after the upgrade will therefore show every finding as new + fixed. Consider a one-time note in the UI or docs.
- The fingerprint is calculated once when the `Finding` is created. If code later changes `endpoint`/`param` on a `Finding` object, the stored fingerprint will be out of date. Nothing does this today, but it's worth keeping in mind.
