## Notes
- When `request_interval_ms == 0`, the jitter fallback sleeps while holding `_lock` (`core/politeness.py:73-82`). That makes jitter-only mode run one request at a time. It is harmless and arguably conservative, but it should be documented.
- Still carried over from R3: about 39 direct `requests.*` calls in plugins, and `get_authenticated_session()` returning the shared Session. Both bypass the scope-checked redirects, the limiter and the 429 handling, and `session.get()` auto-follows redirects carrying auth. These need their own backlog issue.
- `BaseScanner.__init__` still creates its own `PolitenessEngine` (`plugins/base_plugin.py:28`). That instance is only used when a plugin runs without an Engine, because `set_http_client` replaces it with the shared limiter.
