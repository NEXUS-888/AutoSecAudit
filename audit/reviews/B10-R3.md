## Required changes
1. [AUD-27] `core/http_client.py:ScanHttpClient.is_in_scope` — `is_target_allowed(url)` is skipped whenever `self.target` is set, so a public target is treated as in scope and gets requested. This breaks the CLAUDE.md rule "Never bypass `is_target_allowed()`". → Expected: put back the base-commit order. Call `is_target_allowed(url)` first and return `False` when it rejects the URL; only after that apply the same-origin check against `self.target`. Fix tests that use `http://example.com` with a mocked network (e.g. `test_spa_and_dev_hardening.py:360,381`) by switching them to a loopback target such as `http://localhost:5173`. Keep their assertions; do not loosen the client. (Checked next round by: running `ScanHttpClient(target="http://example.com").is_in_scope("http://example.com/x")`, which must be `False`, and by a new test that asserts `request()` returns `None` and never calls `session.send` for a public target.)
2. [AUD-27] `core/http_client.py:_execute_with_redirects` — production code changes which code path runs depending on whether `requests.<method>`/`Session.<method>` is a `Mock`. That is a test-only seam that changes runtime behavior. → Expected: delete the `is_module_mocked`/`is_session_mocked` branches so every request goes through `session.prepare_request` + `session.send`. Existing plugin tests that patch `requests.get`/`requests.post` should be retargeted to patch the shared client, e.g. `patch.object(ScanHttpClient, "request", ...)` or `patch.object(scanner.http.session, "send", ...)`. Keep every assertion. (Checked next round by: grepping `core/http_client.py` for `mock_calls|assert_called`, which must find nothing, and the full suite green.)
