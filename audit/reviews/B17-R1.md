## Notes
- No test asserts the "`data/reports` count unchanged" criterion, since a suite-level check can't sit inside the suite. I'm accepting the mechanism: only `test_full_pipeline.py:99` hardcodes `<repo>/data/reports`, and it removes its own file. `data/reports` currently holds 1341 files, which matches the handoff's before/after count.
- `ui/templates/history.html` (stat cards moved out of `{% if scans %}`) is outside the listed files, and the handoff says "Deviations: none". It looks like a fix for an empty-history test that used to pass only because of the polluted real `data/`, so I'm not blocking on it.
- `core/auth.py:_ensure_db_initialized` adds the DB key to `_initialized_dbs` before `init_user_db()` finishes. A concurrent first request could query before the table exists, and a failed init is never retried. Low risk, but initializing first and marking after would be more robust.
