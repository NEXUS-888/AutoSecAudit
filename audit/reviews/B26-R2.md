## Notes
- The handoff claims `--url` mode auto-generates a timestamped output file. The code actually uses `<YYYY-MM-DD>.json`, the same name as built-in mode, so a `--url` run overwrites that day's built-in results. `--url --write-markdown` also replaces `RESULTS.md` with the external target only.
- `main.py` benchmark dispatch slices `sys.argv[2:]`, which breaks if any global option comes before `benchmark`. Parse with `parse_known_args`, or forward the parsed `args` instead.
- `is_loopback_target` accepts hostnames that resolve to loopback, but the scan resolves them again later (DNS-rebinding window). Consider resolving once and scanning the literal IP.
