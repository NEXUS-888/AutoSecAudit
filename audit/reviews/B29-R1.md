## Required changes
1. [AUD-75] `plugins/graphql_plugin.py:run` Phase 3 (~line 330).
   - **Wrong:** `field_name` and `arg_name` come from the target's introspection response and are interpolated raw into `f"query {{ {field_name}({arg_name}: ...) }}"`. A hostile schema field name such as `x } mutation M { del` makes the scanner send a mutation operation.
   - **Expected:** skip any field or argument name not matching `^[_A-Za-z][_0-9A-Za-z]*$` before probing.
   - **Checked next round by:** a fixture schema field named `a } mutation M { b` must produce no request whose body contains `mutation`, and no crash.
2. [AUD-75] `plugins/graphql_plugin.py:run` SQLi block (~line 394).
   - **Wrong:** `status_diff = probe 500 and baseline 200` is not the "paired status-differential" check. Any GraphQL server that returns 500 on malformed or odd input becomes a Critical SQLi false positive.
   - **Expected:** reuse the existing SQLi paired check from `plugins/sqli_plugin.py` (e.g. broken `'` → error/500 *and* balanced control such as `''` → baseline-like). Also reuse the existing XSS reflection helper and `BaseScanner._get_baseline()`/`_verify_against_baseline()` rather than ad-hoc string comparison. Otherwise, justify the alternative under Deviations.
   - **Checked next round by:** a new fixture field returning HTTP 500 for any input containing a quote (balanced or not) must yield 0 SQLi findings. The existing `sql_query` field must still yield exactly 1.

## Notes
- Probe queries have no selection set and use undeclared `variables`. They fail validation on real schemas where fields return object types, so the fixture's lenient parser hides this. Consider requesting the return type in introspection and adding `{ __typename }` for OBJECT returns.
- Discovery treats any 400 JSON `errors` mentioning "query" as GraphQL (false-positive Info finding). `candidate_paths[:6]` keeps at most one crawler-discovered path. `/graphql/v1` coverage from the old api_abuse check was dropped.
- The `get_remediation` regex OWASP-prefix change is out of scope and unrequested; confirm it doesn't alter remediation text for existing findings.
