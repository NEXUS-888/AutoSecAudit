## Notes
- Bash was denied again this round, so the verdicts rest on reading the code and the tests. I could not run the live local-server probes for the streaming cap and redirects.
- With a real `requests` response and an empty script body, the `.content` fallback after `iter_content` raises `RuntimeError` (the content was already consumed). The broad `except` catches it, so nothing breaks.
- `SequenceMatcher.ratio()` on up to 10k × 10k characters runs on every non-hash-matching 200 response, which could be slow on SPA targets that get many requests. `quick_ratio()` as a pre-filter would make it cheaper. Separately, `Enricher()` built with defaults in tests still reads the real repo cache file, but makes no writes in mock mode.
