## Required changes
1. [AUD-45] `intelligence/enricher.py:Enricher.__init__`: `bool(mock_mode)` ignores `config.MOCK_MODE` when `mock_mode is None`. Expected: `self.mock_mode = bool(mock_mode) if mock_mode is not None else bool(getattr(config, "MOCK_MODE", False))`. Fix the B09 conflict by changing only the constructor calls in `test_b09_shared_http_client.py:532,537` to `Enricher(mock_mode=False, cache_path=None)`, keep every assertion unchanged, and record this under "Deviations". Add a test that sets `config.MOCK_MODE=True`, calls `Enricher()` with no args, enriches a finding with a `cve_id`, and asserts `requests.get` call_count == 0. (Checked next round by: reading `__init__`, plus that new test with `patch("intelligence.enricher.requests.get")`.)
2. [AUD-44] `core/spa_detector.py:SPADetector.is_soft_404`: matches are decided on length plus title only, never on content. Expected: when the hash doesn't match, compare the response against `self.baseline_text` with a content-similarity measure (e.g. `difflib.SequenceMatcher(None, a, b).quick_ratio()`/`ratio()` on capped text, or token-set Jaccard). Return False when similarity < 0.70, before both the `diff<50 / <4 %` branch and the title branch. Add a test where baseline and real page share `<title>`, differ in length by <10 %, and have different bodies (similarity <0.7), and assert `is_soft_404(resp) is False`. Keep the existing positive SPA test (identical/near-identical body → True) green. (Checked next round by: that test plus reading the similarity gate.)
3. [AUD-43] `core/crawler.py:WebCrawler.crawl` (script-fetch loop): the size cap is enforced only after the full download. Expected: call `self._session.get(resolved_script, ..., stream=True)`, skip the script if `Content-Length` is > 2 MB, otherwise read via `iter_content` and stop once more than 2 MB has been read, then `close()`. Also skip parsing if `s_resp.url` is off-origin (`_normalize_url(result.target, s_resp.url) is None`). Add tests that (a) an oversized script (Content-Length or streamed >2 MB) yields none of its endpoints and (b) a script that redirects off-origin is not parsed. (Checked next round by: those tests and reading the loop.)
