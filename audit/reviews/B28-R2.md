## Required changes
1. [AUD-73] `.github/workflows/autosec-scan.example.yml` scan step — lacks `--real`. Without it the CLI falls back to the mock/prompt path, where `prompt_mode_selection` returns `default_mock=True` on EOF, so CI uploads simulated findings and gates on them. → Add `--real`, plus `--skip-reachability-check` only if needed. (Checked next round by: grep the workflow for `--real`.)
2. [AUD-73] `test_b28_ci_output.py::test_authenticated_scan_credentials_redacted_from_reports` — the secret password and cookie never enter the input, so the test cannot fail. → Produce the report from an authenticated run, such as `run_scan(..., login_user, login_pass, sarif=, junit=)` against a loopback CSRF fixture that sets a known session cookie. At minimum, seed the secrets into finding `raw_output`/`evidence`/`request` fields. Then assert both are absent from both files. (Checked next round by: the test feeds the secret into the pipeline and asserts `assertNotIn` on file text.)
3. [AUD-73] `test_b28_ci_output.py::test_cli_sarif_and_junit_flags` — it only checks that the JSON/HTML files exist. → Run the mock scan once with and once without `--sarif/--junit`. Assert the JSON is equal after dropping volatile keys (`timestamp`, `report_id`, durations). (Checked next round by: an equality assertion is present.)
4. [AUD-74] `test_b28_authenticated_dashboard.py::test_password_redaction_everywhere` PDF check — ReportLab Flate-compresses page streams by default, so `assertNotIn(pwd_bytes, pdf_res.data)` is vacuous. → Extract the text (pypdf, or `zlib.decompress` of each FlateDecode stream). Add a positive control, e.g. assert the target host or `auth_status` text is found. Assert `status_code == 200`. (Checked next round by: text extraction plus a positive-control assertion.)
5. [AUD-74] same test — `if report_name:` silently skips the JSON/HTML/PDF checks, and the job dict and `/scan/status` are only checked before the scan runs. → Replace the guard with `assertIsNotNone(report_name)`. Assert 200 on `/download`, `/report` and `/download_pdf`. Re-assert `str(scan_jobs[scan_id])` and the final `/scan/status` body after completion. (Checked next round by: reading the test.)
6. [AUD-74] same test, log capture — the root logger keeps its default level (WARNING), so DEBUG/INFO records never reach the handler, which violates "any log level". → In the `try`, call `logging.getLogger().setLevel(logging.DEBUG)` and give the handler level `NOTSET`. Restore both in `finally`. (Checked next round by: reading the test setup.)
