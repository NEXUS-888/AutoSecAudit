# Handoff: Batch 22 — Round 1

## Issues Addressed
- **AUD-51 · Discovered forms lose everything except field names**
  - Extended `DiscoveredEndpoint` in `core/crawler.py` with `fields`, `enctype`, `form_page`, `form_id`, `form_name`, and `labels`.
  - Updated `_LinkFormParser` in `core/crawler.py` to capture form `enctype`, `id`, `name`, `<label>` text, default values of `<input>` (including `type="hidden"`), `<textarea>` contents, and the first (or `selected`) `<option>` of each `<select>`.
  - Updated `CrawlResult.get_injectable_endpoints()` to preserve `path`, `param`, and `method` while adding `fields`, `enctype`, `form_page`, and `source: "form"` (plus `form_id`, `form_name`, `labels` when present) for form-sourced endpoints.
  - Added `BaseScanner.submit_form_probe(endpoint, param, value)` in `plugins/base_plugin.py`:
    - Enforces same-origin resolution and `is_target_allowed()` scope checks, returning `None` without sending any request when cross-origin or out of scope.
    - Enforces active form-testing deny rules (`DEFAULT_DENY_PATTERN` plus `reset|drop|purge|unsubscribe|deactivate|close-account|password` across action path, form id/name, field names, and labels), returning `None` without sending any request when matched.
    - Re-fetches `form_page` first when any field in `fields` matches `core.authenticator.CSRF_TOKEN_NAMES` and updates the CSRF field with the fresh token before submitting.
    - Replaces only `param` with `value` while preserving all other form fields/defaults, and encodes per `enctype` (`application/x-www-form-urlencoded` or `multipart/form-data`) via `_safe_request`.
- **AUD-52 · SQLi and XSS plugins skip POST form fields**
  - Added `MAX_FORMS_PER_PLUGIN = 8` and `MAX_FIELDS_PER_FORM = 6` constants in `config.py`, plus `BaseScanner._select_form_targets()` in `plugins/base_plugin.py` to prioritize promising field names (`pass/search/id/name/query/url/file/command/...`) while capping probed forms and fields.
  - Updated `SQLiScanner` (`plugins/sqli_plugin.py`) and `XSSScanner` (`plugins/xss_plugin.py`) to probe POST and form-sourced endpoints via `submit_form_probe` using control-vs-payload verification (SQL error signature absent from control; unencoded XSS reflection in HTML-rendered responses).
- **AUD-53 · Command injection, SSTI, SSRF and path traversal skip POST form fields**
  - Updated `CommandInjectionScanner` (`plugins/command_injection_plugin.py`), `SSTIScanner` (`plugins/ssti_plugin.py`), `SSRFScanner` (`plugins/ssrf_plugin.py`), and `PathTraversalScanner` (`plugins/path_traversal_plugin.py`) to test POST and form-sourced endpoints via `submit_form_probe` under the form/field caps and safety rules while preserving control comparison and reflection discounting.
