# Batch 20 — Round 1 Handoff (`AUD-65`, `AUD-66`)

## 1. Summary of Changes

### `AUD-65` — Enforce report and scan-job ownership across dashboard routes
- `core/models.py:55-97`: Added `owner: Optional[str] = None` to `Report` and included `"owner": self.owner` in `Report.to_dict()`.
- `core/pipeline.py:32-119`: Added `owner: Optional[str] = None` to `ScanRequest` and set `report.owner = owner` in `run_scan_pipeline` before saving the report so CLI/MCP scans default to `owner=None` while UI scans persist the submitting user's `user_id`.
- `ui/app.py:86-98`: Added `_can_access_report(user, report_data)` and `_can_access_job(user, job)` helpers so `role == "admin"` can access all reports/jobs (including owner-less CLI/MCP/legacy reports) while non-admin users can only access reports and scan jobs where `owner == user["id"]`.
- `ui/app.py:424-441, 471-505`: Recorded `"owner": current_user["id"]` on `scan_jobs[scan_id]` in `scan_async()` and forwarded `owner=job.get("owner")` to `ScanRequest` in `_run_scan_background()`.
- `ui/app.py:310-322, 534-550, 587-734`: Enforced ownership checks (returning HTTP `404` when unauthorized) on `/scan/progress/<scan_id>`, `/scan/status/<scan_id>`, `/report/<report_id>` (including `/report/latest`), `/download/<report_id>`, `/download_pdf/<report_id>`, `/api/report/<report_id>/waf-rules`, and `/api/report/<report_id>/dev-ticket/<finding_id>`, and filtered `/dashboard` recent reports and `/history` by `_can_access_report`.

### `AUD-66` — Session cookie flags, `sid`-less session bypass, GET logout CSRF, and small correctness fixes
- `config.py:42-69`: Added `resolve_cookie_secure(is_https=False)`, `COOKIE_SECURE`, `SESSION_COOKIE_SECURE`, `SESSION_COOKIE_SAMESITE = "Lax"`, and `SESSION_COOKIE_HTTPONLY = True` honoring `AUTOSEC_COOKIE_SECURE`.
- `ui/app.py:35-69`: Configured `SESSION_COOKIE_HTTPONLY = True`, `SESSION_COOKIE_SAMESITE = "Lax"`, `SESSION_COOKIE_SECURE = config.SESSION_COOKIE_SECURE`, `PERMANENT_SESSION_LIFETIME = timedelta(hours=12)`, and `AutoSecSessionInterface(SecureCookieSessionInterface)` overriding `get_cookie_secure` to default `Secure=True` on HTTPS requests (`request.is_secure` or `X-Forwarded-Proto: https`) while honoring `AUTOSEC_COOKIE_SECURE`.
- `ui/app.py:72-83`: Updated `get_current_user()` to reject sessions without a valid `sid` (`if not sid or auth.is_session_revoked(sid): session.clear(); return None`).
- `ui/app.py:194-200, 270-291`: Set `session.permanent = True` in `login()` and `register()`, and changed `/logout` to `methods=["POST"]` (protected by `AutoSecCSRFProtect`).
- `ui/templates/landing.html:1032-1035`: Replaced `<a href="/logout">` with an inline `<form method="POST" action="/logout">` including `<input type="hidden" name="csrf_token" value="{{ csrf_token() }}">`.
- `core/auth.py:364-379`: Added shared test session helpers `init_test_session(sess, user_id)` and `login_test_client(client, user_id)` that set both `user_id` and `sid`, and updated existing test files that forged sessions via `session_transaction` (`test_b06_dashboard_bugs.py`, `test_b07_scan_management.py`, `test_danger_recipes.py`, `test_history.py`, `test_pdf_download.py`, `test_silent_failures.py`, `test_sse.py`, `test_target_reachability.py`, `test_theme.py`) and updated `/logout` calls in `test_retest_fixes.py` to `POST`.
- `testbed/app.py:13`: Added `import time` so `GET /api/exec?command=sleep` sleeps 2s and returns HTTP `200` instead of raising `NameError: name 'time' is not defined`.
- `intelligence/remediation.py:211-218`: Removed the duplicate `"auth_scanner:idor"` dictionary key.
- `core/http_client.py:49-51, 161-170, 273, 779` & `core/politeness.py:51, 83-102` & `test_b19_scanner_robustness.py:180-181`: Increased `_WatchdogHTTPAdapter` connection pool size to 64, added wire-level dispatch pacing (`pace_wire_send`) so OS socket connect jitter does not compress inter-request arrival gaps, and set `BaseWSGIServer.request_queue_size = 128` in `test_b19_scanner_robustness.py`.

## 2. Tests Added (`test_b20_dashboard_ownership_and_session.py`)
1. `TestAud65ReportAndScanOwnership.test_aud65_user_b_gets_404_on_all_user_a_routes_while_a_and_admin_get_200`: Verifies non-admin user B gets `404` on user A's `/scan/progress/<id>`, `/scan/status/<id>`, `/report/<id>`, `/download/<id>`, `/download_pdf/<id>`, `/api/report/<id>/waf-rules`, and `/api/report/<id>/dev-ticket/<finding_id>`, while user A and admin get `200`.
2. `TestAud65ReportAndScanOwnership.test_aud65_history_isolation_and_ownerless_report_visibility`: Verifies `/history`, `/dashboard`, and `/report/latest` isolate user A's reports from user B, and owner-less CLI/MCP/legacy reports (`owner: None` or absent) are hidden from non-admin users (`404` on direct routes and omitted from `/history`) while remaining visible to admin (`200`).
3. `TestAud65ReportAndScanOwnership.test_aud65_pipeline_and_scan_async_record_owner`: Verifies `run_scan_pipeline(ScanRequest(..., owner=user_a))` writes `"owner": user_a` into saved JSON, default `ScanRequest` writes `"owner": None`, and `POST /scan/async` records `owner == current_user["id"]` on `scan_jobs[scan_id]`.
4. `TestAud66SessionAndSmallCorrectness.test_aud66_login_cookie_flags_samesite_httponly_secure_and_lifetime`: Verifies `POST /login` sets `Set-Cookie` with `HttpOnly`, `SameSite=Lax`, `Max-Age`/`Expires` (`session.permanent = True`), `Secure` on `https://` requests, and honors `AUTOSEC_COOKIE_SECURE=true`/`false`.
5. `TestAud66SessionAndSmallCorrectness.test_aud66_forged_session_without_sid_rejected_with_302`: Verifies a session containing `user_id` without `sid` is rejected (`GET /dashboard` returns `302` to `/login`).
6. `TestAud66SessionAndSmallCorrectness.test_aud66_logout_requires_post_with_csrf_and_get_does_not_logout`: Verifies `GET /logout` returns `405` and does not clear the session, `POST /logout` without CSRF returns `400` and does not clear the session, `POST /logout` with CSRF logs out and revokes `sid`, and `ui/templates/landing.html` uses `<form method="POST" action="/logout">` with `csrf_token`.
7. `TestAud66SessionAndSmallCorrectness.test_aud66_testbed_api_exec_sleep_returns_200_after_2s`: Verifies `testbed/app.py` `GET /api/exec?command=sleep` returns `200` after ~2s instead of `500` `NameError`.
8. `TestAud66SessionAndSmallCorrectness.test_aud66_remediation_py_has_no_duplicate_dict_keys_ast`: Parses `intelligence/remediation.py` with `ast` and asserts every `ast.Dict` has unique literal keys.
