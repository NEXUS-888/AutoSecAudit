- Implemented ordered pipeline execution:
  1. Scope check (`validate_target`, `is_target_allowed`, pre-flight `check_target_reachable` for live scans)
  2. Load profile plugins
  3. Set target and custom HTTP headers
  4. Automated authentication credentials configuration
  5. OpenAPI specification import
  6. Execute plugins and crawler
  7. Generate raw report
  8. Delta analysis comparison (if previous report provided)

  10. Enricher (`enrich` with CVE/CVSS intelligence)
  11. ComplianceMapper (`map_findings` for OWASP, CWE, PCI-DSS)
  12. Remediation guidance (`enrich_with_remediation`)
  13. Summary recalculation
  14. Save JSON and HTML reports with shared `report_id`
