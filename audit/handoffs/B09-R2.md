# Handoff B09-R2

## Target Issues
- **AUD-25**: No shared, scope-aware HTTP layer (`core/http_client.py`, `plugins/base_plugin.py`, `core/engine.py`, `core/politeness.py`)
- **AUD-26**: 429/503 responses are fed into detection logic (`core/politeness.py`, `core/http_client.py`, `core/models.py`, `core/engine.py`)

## Round 2 Revisions Addressing B09-R1 Feedback

1. **[AUD-25] Real Global Rate Limiter in `PolitenessEngine.pace_request` (`core/politeness.py`)**:
   - Replaced per-call jitter with a thread-safe virtual schedule rate limiter.
   - Maintains `self._next_allowed_at` under `self._lock`. When `self.request_interval_ms > 0` (or `pacing_ms`), each concurrent caller reserves `scheduled_time = max(now, self._next_allowed_at)`, advances `self._next_allowed_at = scheduled_time + interval`, and sleeps outside the lock until `scheduled_time`.
   - Added high-resolution timing via `time.monotonic()` and a precision wait loop ensuring callers never fire before their assigned slot.
   - Tested by firing 10 concurrent requests via `ThreadPoolExecutor` at a local `ThreadedServer` with pacing set to 100 ms, asserting individual gaps >= 70 ms and mean gap >= 90 ms.

2. **[AUD-25] Malformed Redirect Location / Port Handling (`core/http_client.py`)**:
   - Wrapped `ScanHttpClient.is_in_scope()` in `try ... except (ValueError, Exception)` to safely catch port range errors (`ValueError: Port out of range 0-65535`) from `urlsplit`/`urlparse` on malformed redirect URLs like `http://127.0.0.1:99999/overflow`.
   - Returns `False` on any malformed URL, treating the hop as out-of-scope and blocking the redirect without raising.
   - Wrapped `ScanHttpClient.request()` in a top-level `try ... except Exception` block ensuring `request()` never raises unhandled exceptions to plugins.
   - Added initial URL scope validation before request dispatch (addressing Note 1 from review).
   - Added `test_aud25_malformed_redirect_port_out_of_range_does_not_raise` against a live local server returning a 302 to port 99999.

3. **[AUD-26] Surface `throttled_count` and Thread-Safe Atomic Counter (`core/http_client.py`, `core/models.py`, `core/engine.py`)**:
   - Protected `_throttled_count` in `ScanHttpClient` under `self._lock` with thread-safe property getter/setter and atomic `increment_throttled_count()`.
   - Added `throttled_requests: int = 0` field to `core/models.py:Report` and included it in `to_dict()`.
   - Updated `Engine._generate_summary` to include `"throttled_requests": self.http_client.throttled_count`.
   - Updated `Engine.generate_report()` to populate `Report.throttled_requests`.
   - Added `Engine.throttled_requests` property forwarding to `self.http_client.throttled_count`.
   - Added `test_aud26_engine_exposes_throttled_requests_in_report` verifying `throttled_requests` appears in report dict and summary.

4. **[AUD-26] Fixed `test_aud26_always_503_server_returns_none` (`test_b09_shared_http_client.py`)**:
   - Mocked `client.session.send = MagicMock(return_value=resp_503)` with `resp_503.headers = {"Retry-After": "0.01"}`.
   - Patched `time.sleep` to prevent test delays.
   - Asserted `resp is None`, `send.call_count == client.max_retries_on_429 + 1`, and `client.throttled_count` incremented.

5. **[AUD-26] Single Source of Truth for `max_retries_on_429` (`core/http_client.py`)**:
   - When `max_retries_on_429` is not explicitly provided to `ScanHttpClient`, it defaults to `self.politeness.max_retries_on_429`.
   - Added `test_aud26_single_source_of_truth_max_retries` verifying `ScanHttpClient(politeness=PolitenessEngine(max_retries_on_429=1))` calls `send` exactly 2 times (1 initial + 1 retry) on always-429.
