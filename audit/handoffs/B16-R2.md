# Handoff B16 round 2

## AUD-43 — Crawler is a DFS that never reads JS bundles
- Changes: `core/crawler.py`:
  - Replaced recursive DFS with iterative BFS using a queue (`collections.deque([(target, 0)])`), preserving `self.max_depth` and `self.max_pages`.
  - Added strict same-origin checks (`_normalize_url` comparing scheme + hostname + port, plus discarding off-origin redirects) for both HTML links and script tags.
  - Implemented same-origin `<script src>` fetching: enforces maximum of 10 script files per session and 2 MB size cap, and invokes `extract_js_endpoints` on script content.
  - Updated `_API_PATTERN` and `extract_js_endpoints` to record implied HTTP methods from `.post(`, `.put(`, `.delete(`, `.get(`, and `fetch(`. Prevented implicit REST path literals from overriding explicit HTTP methods.
- Criteria → tests: Root page with `<script src="/app.js">` containing `fetch('/api/items?id=1')` yields `/api/items` with param `id` → `test_b16_discovery.py::TestAUD43Crawler.test_acceptance_script_src_yields_endpoint_and_param`
- Criteria → tests: Crawler visits in BFS order rather than recursive DFS → `test_b16_discovery.py::TestAUD43Crawler.test_crawler_uses_bfs_order`
- Criteria → tests: Discovered endpoints record implied HTTP methods from `.post(`, `.put(`, `.delete(` → `test_b16_discovery.py::TestAUD43Crawler.test_crawler_js_http_methods_implied`
- Criteria → tests: Off-origin scripts ignored and script count capped at 10 files → `test_b16_discovery.py::TestAUD43Crawler.test_crawler_same_origin_and_script_limits`

## AUD-44 — SPA soft-404 detection
- Changes: `core/spa_detector.py`:
  - Updated `_calibrate` to send 2-3 randomized probes (including a probe with `.html` file extension) following redirects (`allow_redirects=True`, matching scanner plugin policy).
  - Configured `is_soft_404` so title equality only counts together with length/similarity tolerance. Content difference greater than 30% is never flagged as a soft-404.
  - Added `calibrate: bool = True` optional flag to `SPADetector.__init__` to allow offline/unit-test initialization without network overhead.
- Changes: `plugins/base_plugin.py`:
  - Added `BaseScanner.set_spa_detector(spa_detector: SPADetector)` allowing scanner plugins to receive the shared, pre-calibrated detector from the engine.
- Changes: `core/engine.py`:
  - Added `Engine.spa_detector: Optional[SPADetector] = None`.
  - Added `Engine.calibrate_spa_detector(target)` to calibrate once per scan and share the calibrated detector instance with all loaded plugins.
  - In `run_plugins()`, calibrated once in real active scan mode before plugin execution.
- Criteria → tests: Site with shared title whose real page differs by > 30% in content is not flagged as soft-404 → `test_b16_discovery.py::TestAUD44SPASoft404.test_acceptance_site_with_shared_title_differing_by_over_30_percent_not_soft_404`
- Criteria → tests: Calibration sends 2-3 probes (including file extension) with `allow_redirects=True` → `test_b16_discovery.py::TestAUD44SPASoft404.test_spa_calibration_probes_and_redirect_policy`
- Criteria → tests: Engine calibrates once and shares detector across all plugins → `test_b16_discovery.py::TestAUD44SPASoft404.test_engine_calibrates_once_and_shares_with_plugins`

## AUD-45 — Enricher hits the network in mock mode
- Changes: `intelligence/enricher.py`:
  - In mock mode (`self.mock_mode = bool(mock_mode)`), `_fetch_cve_data` makes zero network calls and returns None/cached data immediately.
  - Added persistent disk cache with TTL (`data/cve_cache.json`, default 30 days TTL).
  - Guarded disk cache save and load so empty entries (where both `cvss_score` and `references` are empty) are never saved or returned as valid data.
  - Saved successful HTTP 200 API responses from NVD and CIRCL to disk cache with timestamps.
  - Added support for `NVD_API_KEY` header (`apiKey`) when configured via environment or config.
- Criteria → tests: In mock mode, enriching finding with `cve_id` makes zero HTTP calls → `test_b16_discovery.py::TestAUD45Enricher.test_acceptance_mock_mode_zero_http_calls`
