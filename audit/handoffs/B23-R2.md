1. **[AUD-56] BFS page fetch and crawl resilience (core/crawler.py:635-641, 816-834):**
   - In `core/crawler.py:WebCrawler.crawl`, child page fetches catch general `Exception` rather than only `requests.RequestException`.    - Also added `try...except Exception` guard around inline JavaScript endpoint extraction (`core/crawler.py:816-834`) to prevent malformed script responses from aborting BFS.
   - Added `test_child_page_exception_does_not_raise_and_records_error` in `test_b23_crawler_coverage.py::TestAUD56CrawlerResilience` verifying that when `session.get` returns HTML for the root page and raises `ValueError("boom")` for a child page, `crawl()` returns without raising, with `start_ok=True`, `pages_visited >= 1`, `fetch_failures >= 1`, and `result.errors` mentioning `/child-error`.
