# Handoff B16 round 3

## AUD-43 — Crawler is a DFS that never reads JS bundles
- Changes: `core/crawler.py`:
  - Streaming size cap: In the `<script src>` fetching loop, requests are now made with `stream=True`.
  - Content-Length check: If `Content-Length` header exceeds 2 MB, the script is skipped immediately without reading the body, and the response is closed.
  - Streamed chunk limit: Read chunks via `iter_content(chunk_size=65536)` and aborts immediately if total bytes read exceeds 2 MB, closing the response.
  - Redirect origin check: After redirects, checks `_normalize_url(result.target, s_resp.url) is None`. If the script redirected off-origin, parsing is skipped and the response is closed.
  - Resource cleanup: `s_resp.close()` is guaranteed to execute in a `finally` block for every fetched script.
- Criteria → tests: Root page with `<script src="/app.js">` containing `fetch('/api/items?id=1')` yields `/api/items` with param `id` → `test_b16_discovery.py::TestAUD43Crawler.test_acceptance_script_src_yields_endpoint_and_param`
- Criteria → tests: Crawler visits in BFS order rather than recursive DFS → `test_b16_discovery.py::TestAUD43Crawler.test_crawler_uses_bfs_order`
- Criteria → tests: Discovered endpoints record implied HTTP methods from `.post(`, `.put(`, `.delete(` → `test_b16_discovery.py::TestAUD43Crawler.test_crawler_js_http_methods_implied`
- Criteria → tests: Off-origin scripts ignored and script count capped at 10 files → `test_b16_discovery.py::TestAUD43Crawler.test_crawler_same_origin_and_script_limits`
- Criteria → tests: Oversized script via Content-Length header (>2 MB) yields none of its endpoints → `test_b16_discovery.py::TestAUD43Crawler.test_crawler_oversized_script_content_length_yields_no_endpoints`
- Criteria → tests: Oversized script streamed (>2 MB) yields none of its endpoints → `test_b16_discovery.py::TestAUD43Crawler.test_crawler_oversized_script_streamed_yields_no_endpoints`
- Criteria → tests: Script redirecting off-origin is discarded and not parsed → `test_b16_discovery.py::TestAUD43Crawler.test_crawler_script_off_origin_redirect_not_parsed`

## AUD-44 — SPA soft-404 detection
- Changes: `core/spa_detector.py`:
  - Content similarity gate: When response hash does not match `baseline_hash`, response is compared against `self.baseline_text` using `difflib.SequenceMatcher(None, self.baseline_text[:10000], resp.text[:10000]).ratio()`.
  - Immediate exit on low similarity: If `similarity < 0.70`, `is_soft_404` returns `False` immediately, before the length tolerance check (`diff < 50` or `diff_ratio < 0.04`) and before the title equality check.
  - Multi-probe calibration with file extension and `allow_redirects=True`.
- Changes: `plugins/base_plugin.py` & `core/engine.py`:
  - Shared detector: `Engine.calibrate_spa_detector` calibrates once per scan and injects `spa_detector` into all loaded plugins via `BaseScanner.set_spa_detector`.
- Criteria → tests: Site with shared title whose real page differs by > 30% in content is not flagged as soft-404 → `test_b16_discovery.py::TestAUD44SPASoft404.test_acceptance_site_with_shared_title_differing_by_over_30_percent_not_soft_404`
- Criteria → tests: Shared title with <10% length difference and different body (similarity <0.70) is not flagged as soft-404 → `test_b16_discovery.py::TestAUD44SPASoft404.test_spa_shared_title_similar_length_different_body_not_soft_404`
- Criteria → tests: Near-identical SPA fallback body (similarity >= 0.70) is flagged as soft-404 → `test_b16_discovery.py::TestAUD44SPASoft404.test_spa_near_identical_body_is_soft_404`
- Criteria → tests: Calibration sends 2-3 probes (including file extension) with `allow_redirects=True` → `test_b16_discovery.py::TestAUD44SPASoft404.test_spa_calibration_probes_and_redirect_policy`
- Criteria → tests: Engine calibrates once and shares detector across all plugins → `test_b16_discovery.py::TestAUD44SPASoft404.test_engine_calibrates_once_and_shares_with_plugins`

## AUD-45 — Enricher hits the network in mock mode
- Changes: `intelligence/enricher.py`:
  - Fallback to config: In `Enricher.__init__`, `self.mock_mode = bool(mock_mode) if mock_mode is not None else bool(getattr(config, "MOCK_MODE", False))`.
  - When `mock_mode` is True, `_fetch_cve_data` makes zero HTTP calls and returns None/cached data.
  - Default disk cache path `DEFAULT_CACHE_PATH` anchored to project root `data/cve_cache.json`.
  - Disk cache saves and loads with 30-day TTL; empty CVE entries are excluded.
  - Supports `NVD_API_KEY` header (`apiKey`).
