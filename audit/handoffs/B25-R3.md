## Deviations
- `plugins/xss_plugin.py`: Refined benign static navigation detection for `location.href` / `window.location` assignments to inspect the complete RHS expression up to statement/attribute boundaries. This prevents false negatives on DOM sinks using string concatenation (e.g. `location.href='/x?c='+document.cookie` and `window.location='/a'+location.hash`) while preserving suppression of static string navigation (e.g. `window.location.href='/labs/sqli'`).
- `test_b22_regression_testbed.py`: Converted from wildcard import (`import *`) to a lightweight import/route registration smoke test. This prevents `run_tests.py` from executing the ~70s full pipeline scan twice during unittest discovery.
- `test_b19_scanner_robustness.py`: Adjusted chunk size in `/fast_oversized` from 32 KiB to 128 KiB so the response size threshold (64 KiB) is exceeded on the first chunk rather than requiring multiple WSGI generator iterations, eliminating thread scheduling flakiness during 50 concurrent requests.
