## AUD-48 — Static Page Reflection vs. Execution Proof & Control-Gating
- Changes: `plugins/command_injection_plugin.py`:
  - **Control-Absence Requirement (`check_command_exec_proof`):** Implemented helper function ensuring that every execution signature present in the test response must be **absent** from the inert control response (`inert_text` / `j_inert_text`). If a signature appears in both the test and control responses, it is discarded as static page reflection.
  - **Strict UID Regex:** Replaced bare `"uid="` with strict regex `r"uid=\d+\(\w+\)\s+gid=\d+"` and exact `"uid=0(root)"`.
  - **JSON Body Control-Gating:** Applied the same control-absence rule to deep JSON body injection path by fetching baseline `j_inert` before fuzzing.
  - **Confidence Gating:** If `inert_resp` is `None` (no control baseline), confidence is recorded as `"medium"` instead of `"high"`.
  - **Method Preservation:** Preserved `method` accurately in `parse_output()` (`result.get("method", "POST" if "body" in str(result) else "GET")`).

## AUD-50 — Testbed Full-Plugin Scan Canonical Merge & Taxonomy Harmonization
- Changes: `intelligence/taxonomy.py`:
  - **Header Taxonomy Aliases:** Added `"x_xss_protection"`, `"x-xss-protection"`, `"missing security header"`, `"security header"`, `"security headers"` -> `VulnType.MISCONFIG.value` to `TAXONOMY_ALIASES`.
  - **Fallback Rule Order:** Positioned missing security header classification before the generic XSS rule in `FALLBACK_RULES` (`r"\b(missing (?:security )?header|\w+ header missing|security headers?|x-xss-protection)\b"` -> `misconfig`). Also added negative lookbehind/lookahead to the XSS rule (`r"(?<!x-)\b(xss|...)\b(?!-protection)"`).
