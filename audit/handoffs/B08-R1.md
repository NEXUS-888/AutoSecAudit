# Handoff B08-R1

## Target Issues
- **AUD-22**: Auto-login reports success on failed logins (`core/authenticator.py`)
- **AUD-23**: Credential spraying across 14 paths -> account lockout (`core/authenticator.py`)
- **AUD-24**: Crawler follows logout/destructive links and leaves scope on redirect (`core/crawler.py`)

## Root Cause Summary
- **AUD-22**: `AutoAuthenticator._evaluate_auth_response` treated any existing cookies in the session (such as session or CSRF cookies set during login page GET) combined with a 200 OK as a successful login. Failure indicator strings were only checked on error status codes (400, 401, 403), ignoring 200 OK responses with failure messages like `"Invalid email or password"`. Furthermore, nested JSON token responses such as OWASP Juice Shop's `{"authentication": {"token": "..."}}` were not parsed, and no post-login verification against a baseline URL was executed.
- **AUD-23**: `AutoAuthenticator` sprayed credentials across up to 14 discovered candidate paths even when endpoints had no login forms or clearly rejected the credentials, potentially causing account lockouts.
- **AUD-24**: `WebCrawler` had no deny-pattern filtering on discovered links or forms, causing it to request destructive actions (e.g., `/logout`, `/delete`, `/destroy`). Additionally, `_normalize_url` only checked hostnames rather than scheme + host + port, and redirects to off-origin hosts were not discarded.

## Changes Made per File
- `core/crawler.py`:
  - Added `DEFAULT_DENY_PATTERN = r"logout|log-out|signout|sign-out|logoff|delete|remove|destroy"`.
  - Added `deny_pattern` parameter to `WebCrawler.__init__` (accepts custom regex, string, or None).
  - Implemented `_is_denied()` checking URLs, actions, and discovered endpoints against the deny regex prior to fetching or recording.
  - Enhanced `_normalize_url` to enforce exact origin matching `(scheme, hostname, port)`.
  - Added off-origin redirect discard check in `_crawl_page` comparing target origin `(scheme, hostname, port)` with `resp.url`.
- `core/authenticator.py`:
  - Added `DEFAULT_DENY_PATTERN` to skip logout/delete endpoints during login candidate discovery.
  - Snapshot session cookies immediately before each credential POST (`_snapshot_cookies`).
  - Added `FAILURE_INDICATORS` check unconditionally on all HTTP status codes (including 200 OK).
  - Implemented recursive nested token extraction in `_extract_token_from_json` supporting nested dictionaries such as `authentication.token`.
  - Implemented `_verify_authenticated_session` comparing post-login requests to verify URLs with anonymous baseline requests to confirm true session state.
  - Hard-capped credential submissions at 6 (`MAX_CREDENTIAL_SUBMISSIONS`) per `authenticate()` call.
  - Filtered candidate endpoints to only submit credentials to endpoints with password forms or answering 400/401/422 to an empty JSON POST (`_is_valid_login_endpoint`).
  - Implemented `_is_clear_credential_rejection` to stop credential spraying immediately after the first endpoint clearly rejects the credentials.
- `test_b08_auth_and_crawler.py`:
  - Created unit tests covering all acceptance criteria for AUD-22, AUD-23, and AUD-24.
