# Handoff B17 round 1

## AUD-46 — Tests write into the real data/ directory
- Changes: `config.py`:
  - Added `_get_data_dir()` reading `AUTOSEC_DATA_DIR` environment variable with fallback to `<BASE_DIR>/data`.
  - Added `_get_reports_dir()` resolving `<DATA_DIR>/reports`.
  - Exported dynamic properties `DATA_DIR` and `REPORTS_DIR` via module `__getattr__` and `__dir__`, ensuring dynamic runtime resolution when `AUTOSEC_DATA_DIR` is set or patched.
  - Updated `_get_or_create_secret_key()` to use `_get_data_dir()` for `.secret_key` path.
- Changes: `core/auth.py`:
  - Removed eager top-level `init_user_db()` execution on module import.
  - Implemented lazy database initialization: `_ensure_db_initialized()` is invoked on first database access via `_get_db()` or explicit `init_user_db()`.
  - Retained `DB_PATH` as a stable module-level attribute.
- Changes: `run_tests.py`:
  - When running the test suite, automatically creates an isolated temporary directory and points `os.environ["AUTOSEC_DATA_DIR"]` to it, ensuring `reports` subdirectory exists.
  - Restores environment and cleans up the temporary directory upon test completion.
- Changes: `ui/templates/history.html`:
  - Positioned summary stats cards outside `{% if scans %}` so the scan history dashboard stats metrics ("Total Scans") render consistently across both empty and populated states.
- Criteria → tests: `AUTOSEC_DATA_DIR` redirects `config.DATA_DIR` and `config.REPORTS_DIR` → `test_b17_hygiene.py::TestAUD46DataDirHygiene.test_autosec_data_dir_environment_override`
- Criteria → tests: Importing `core.auth` creates no database file on disk → `test_b17_hygiene.py::TestAUD46DataDirHygiene.test_core_auth_no_db_created_on_import`
- Criteria → tests: Database is initialized lazily upon first use (e.g. `create_user` or `init_user_db`) → `test_b17_hygiene.py::TestAUD46DataDirHygiene.test_core_auth_lazy_initialization_on_first_use`
- Criteria → tests: Running the full test suite leaves `data/reports` file count unchanged (verified 1341 files before and 1341 files after `python run_tests.py`)
