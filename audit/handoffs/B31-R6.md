## Deviations & Design Choices
- **`Connection: close` header:** Non-SSE responses explicitly send `Connection: close` to prevent Werkzeug's single-process development server from exhausting worker threads or dropping connections on Windows loopback under concurrent test requests.
- **`REPORT_ID_PATTERN` (`ui/app.py:314`):** Uses `re.compile(r"^(?!.*\.\.)[\w\.-]+$")`. Safely accommodates single dot extensions used in sidecar/probe tests (`scan_<id>.triage`) while strictly preventing path traversal via negative lookahead `(?!.*\.\.)` (blocking `..`) and excluding directory separators `/` and `\`. Non-conforming patterns (e.g. `bad$id`) fail match and return 404.
- **Webhook parameter in `scan_async`:** Updated `/scan/async` to accept optional `webhook` parameter and forward it to `_run_scan_background` and `ScanRequest`, ensuring end-to-end webhook integration with cancellation checkpoints.
