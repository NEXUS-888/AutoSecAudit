# Handoff B09-R1

## Target Issues
- **AUD-25**: No shared, scope-aware HTTP layer (`core/http_client.py`, `plugins/base_plugin.py`, `core/engine.py`, `core/politeness.py`)
- **AUD-26**: 429/503 responses are fed into detection logic (`core/politeness.py`, `core/http_client.py`)

## Root Cause Summary
- **AUD-25**: Plugins executed direct `requests.*` calls or spun up separate sessions, lacking unified authentication propagation, scope validation across redirects, global rate-limiting synchronization, and utilizing randomized rotating User-Agents which caused jitter and noise in baseline comparisons.
- **AUD-26**: When target services responded with HTTP 429 or 503, the client slept briefly but still returned the throttled response to plugin detection logic, causing false positive vulnerability reports. The configured `max_retries_on_429` was unused, and `Retry-After` headers were ignored.

## Changes Made per File
- `core/http_client.py` (new):
  - Created `ScanHttpClient`, owned by the `Engine` and injected into plugins.
  - Maintains a single `requests.Session` carrying auth headers and cookies.
  - Configures stable User-Agent `AutoSecAudit/2.0` across all requests without rotation.
  - Shares a thread-safe `PolitenessEngine` rate limiter across plugins.
  - Enforces manual, hop-by-hop redirect following with strict scope verification (`is_in_scope`: same origin + `is_target_allowed`). Redirects to out-of-scope hosts are blocked.
  - Implements automatic retry for HTTP 429/503 with exponential backoff up to `max_retries_on_429`, honoring `Retry-After` headers (both integer seconds and HTTP dates).
  - If a target remains throttled after maximum retries, increments `throttled_count` and returns `None`. Never feeds 429/503 to plugin logic.
- `core/politeness.py`:
  - Removed User-Agent rotation; uses constant `AutoSecAudit/2.0`.
  - Added thread-safe locking with `threading.Lock()` across `pace_request` and `handle_response_status`.
- `plugins/base_plugin.py`:
  - Added `http` attribute and `set_http_client` injection method to `BaseScanner`.
  - Added `_get_http_client` lazy initializer for standalone scanner instances.
  - Delegated `set_auth` and `get_authenticated_session` to the shared `ScanHttpClient`.
  - Delegated `_safe_request` to `self.http.request`, keeping the exact public signature and parameters intact.
  - Updated `_get_baseline` to delegate to `self._safe_request` rather than uncoordinated direct `requests.get`/`post`.
- `core/engine.py`:
  - Initialized `self.http_client = ScanHttpClient(...)` on `Engine.__init__`.
  - Synchronized target on `set_target`.
  - Added `setup_shared_http_client` to bind authentication and inject `self.http_client` into all loaded plugins.
- `test_b09_shared_http_client.py` (new):
  - Added 9 unit tests verifying all acceptance criteria for AUD-25 and AUD-26.
